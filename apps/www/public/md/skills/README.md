# Arlo UI skill (`skills/`)

The Arlo UI design skill: a portable bundle of design rules, tokens, and patterns that AI agents (Cursor, Claude Code, Codex, …) load on demand. It blends disciplined restraint, data-forward composition, and meticulous interaction polish into a system that feels like its own.

This folder lives at the **repo root** (same pattern as [HeroUI v3 `skills/`](https://github.com/heroui-inc/heroui/tree/v3/skills)) so skills stay visible alongside `apps/` and `packages/`. There is **no extra `arloui/` subfolder in git**—`SKILL.md` and `references/` sit directly under `skills/`. When you install into an agent, you still copy or symlink into a directory named **`arloui`** so the skill id matches tooling defaults (`~/.cursor/skills-cursor/arloui`, etc.).

Published mirror (no clone required): [`https://arloui.com/md/skills/SKILL.md`](https://arloui.com/md/skills/SKILL.md) — the full pack is under `/md/skills/` on the docs site. See also [/docs/agents/skill-pack](https://arloui.com/docs/agents/skill-pack).

The hand-authored markdown is the design contract; `npm run skill:sync` (run from the repo root) writes generated machine-readable refs (`tokens.json`, `registry.json`, `usage.md`) under `skills/references/`.

## Layout

```
skills/
├── README.md                 maintainer-facing (optional to copy into agents)
├── SKILL.md                  entry point: rules, workflow, output conventions
├── component-debt.md         maintainer-facing: where the shipped code owes the spec
└── references/
    ├── tokens.md             hand-authored: type, color, spacing, radius, motion
    ├── components.md         hand-authored: primitives, variants, screen recipes
    ├── platform-mapping.md hand-authored: Figma ↔ React Native ↔ SwiftUI
    ├── tokens.json           generated by npm run skill:sync
    ├── registry.json         generated by npm run skill:sync
    └── usage.md              generated by npm run skill:sync
```

`SKILL.md` uses the standard YAML frontmatter format (`name`, `description`, `version`) consumed by Anthropic Agent Skills and Cursor skills. Tools that read `AGENTS.md` can include it as a referenced guidance file.

## Editing

Editing falls into two clean categories:

| You're changing…                                | Edit here                                                  | Then run                  |
| ----------------------------------------------- | ---------------------------------------------------------- | ------------------------- |
| Design intent (tokens.md / components.md / …)   | `skills/references/*.md` (not `usage.md`)                  | nothing — that's the spec |
| Token values, registry contents, CLI behavior   | `packages/tokens/`, `packages/registry/`, `packages/cli/`  | `npm run skill:sync`      |

`npm run skill:sync` regenerates only the JSON files and `usage.md`. CI fails if those drift.

## Installing the skill into your agent

This is a folder copy. Pick the agent you use. Replace **`skills`** as the source—**`arloui`** is the destination folder name the agents expect.

### Cursor

```bash
# user-level (available in every project)
mkdir -p ~/.cursor/skills-cursor
cp -R skills ~/.cursor/skills-cursor/arloui

# or symlink during local development so updates flow automatically:
ln -s "$(pwd)/skills" ~/.cursor/skills-cursor/arloui

# project-level (lives inside the consumer repo, scoped to that project):
mkdir -p .cursor/skills && cp -R skills .cursor/skills/arloui
```

### Claude Code

```bash
# user-level
mkdir -p ~/.claude/skills && cp -R skills ~/.claude/skills/arloui

# project-level
mkdir -p .claude/skills && cp -R skills .claude/skills/arloui
```

### Codex CLI / generic agents (`AGENTS.md`)

```bash
cp -R skills ./arloui
```

Then add a pointer in your `AGENTS.md`:

```md
## Design

For mobile UI work, follow the Arlo UI skill at `./arloui/SKILL.md`.
```

Or use **`node scripts/install-skill.mjs cursor --symlink`** from the repo root (same layout).

## Compatibility

| Agent           | Status      | Install location                              |
| --------------- | ----------- | --------------------------------------------- |
| Cursor          | Supported   | `~/.cursor/skills-cursor/arloui`              |
| Claude Code     | Supported   | `~/.claude/skills/arloui`                     |
| Codex CLI       | Supported   | `./arloui` referenced from `AGENTS.md`        |
| Other agents    | Best-effort | Any tool that reads `SKILL.md` / `AGENTS.md`  |

## Status

Pre-1.0. Skill content, token values, and install paths may change between minor releases. Once `1.0.0` ships, breaking changes will follow [semver](https://semver.org/) and be documented in the repo changelog.
