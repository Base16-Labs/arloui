# Fluidity
<Lede>Interfaces that feel alive, responsive, and natural.</Lede>

Fluidity in ArloUI is not just about animations; it's about the unbroken thread of interaction from the moment a user touches the glass to the moment the system responds.

When we talk about fluidity, we mean the physical rules of the interface.<Footnote id="1" /> Elements should have mass, momentum, and friction. They shouldn't just teleport from state A to state B.

### The 120ms Rule
Every interactive element must respond visually within 120ms of a touch event. This is the threshold of human perception for cause and effect. If an action takes longer, the user feels disconnected from the interface.

### Continuous Gestures
Interactions should not be discrete. A swipe should track perfectly with the user's finger. When the user releases, the velocity of their swipe should dictate the momentum of the element.
