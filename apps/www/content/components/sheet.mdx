## When to use
- **Interruptive flows:** When the user must complete a sub-task before continuing.
- **Context preservation:** When the user needs to see the underlying screen to make a decision.
- **Mobile-first:** Prefer sheets over center modals on mobile.

## Archetypes
Used in the following compositional patterns:
- Sheet over content
- Composer
- Paywall

## Motion
- **Curve:** `spring-smooth` (stiffness: 300, damping: 28)
- **Duration:** Typically resolves in ~350ms.
- **Reduced Motion:** Fallback to a 200ms opacity fade.

## Accessibility
- Must trap focus while open.
- Must dismiss on Escape key (web/hardware keyboard).
- Must have an accessible dismiss button if swipe-to-dismiss is not obvious.

## Do / Don't
<DoDont>
