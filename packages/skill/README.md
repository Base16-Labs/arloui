# @arloui/skill

The Arlo UI design skill: a portable bundle of design rules, tokens, and patterns that AI agents (Cursor, Claude Code, Codex, …) load on demand. It blends Nothing-inspired restraint, data-forward composition, and Emil-style interaction polish into a system that feels like its own.

This package lives inside the arloui monorepo so the skill and the runtime implementation can never drift. The hand-authored markdown is the design contract; `pnpm skill:sync` (run from the repo root) writes generated machine-readable refs (`tokens.json`, `registry.json`, `usage.md`) next to the markdown.

## Layout

```
packages/skill/
└── arloui/
    ├── SKILL.md                       entry point: rules, workflow, output conventions
    └── references/
        ├── tokens.md                  hand-authored: type, color, spacing, radius, motion
        ├── components.md              hand-authored: primitives, variants, screen recipes
        ├── platform-mapping.md        hand-authored: Figma ↔ React Native ↔ SwiftUI
        ├── tokens.json                generated by pnpm skill:sync
        ├── registry.json              generated by pnpm skill:sync
        └── usage.md                   generated by pnpm skill:sync
```

`SKILL.md` uses the standard YAML frontmatter format (`name`, `description`, `version`) consumed by Anthropic Agent Skills and Cursor skills. Tools that read `AGENTS.md` can include it as a referenced guidance file.

## Editing

Editing falls into two clean categories:

| You're changing…                                | Edit here                                                  | Then run                  |
| ----------------------------------------------- | ---------------------------------------------------------- | ------------------------- |
| Design intent (tokens.md / components.md / …)   | `packages/skill/arloui/references/*.md`                    | nothing — that's the spec |
| Token values, registry contents, CLI behavior   | `packages/tokens/`, `packages/registry/`, `packages/cli/`  | `pnpm skill:sync`         |

`pnpm skill:sync` regenerates only the JSON files and `usage.md`. CI fails if those drift.

## Installing the skill into your agent

This is a folder copy. Pick the agent you use:

### Cursor

```bash
# user-level (available in every project)
mkdir -p ~/.cursor/skills-cursor
cp -R packages/skill/arloui ~/.cursor/skills-cursor/arloui

# or symlink during local development so updates flow automatically:
ln -s "$(pwd)/packages/skill/arloui" ~/.cursor/skills-cursor/arloui

# project-level (lives inside the consumer repo, scoped to that project):
mkdir -p .cursor/skills && cp -R packages/skill/arloui .cursor/skills/arloui
```

### Claude Code

```bash
# user-level
mkdir -p ~/.claude/skills && cp -R packages/skill/arloui ~/.claude/skills/arloui

# project-level
mkdir -p .claude/skills && cp -R packages/skill/arloui .claude/skills/arloui
```

### Codex CLI / generic agents (`AGENTS.md`)

```bash
cp -R packages/skill/arloui ./arloui
```

Then add a pointer in your `AGENTS.md`:

```md
## Design

For mobile UI work, follow the Arlo UI skill at `./arloui/SKILL.md`.
```

## Compatibility

| Agent           | Status      | Install location                              |
| --------------- | ----------- | --------------------------------------------- |
| Cursor          | Supported   | `~/.cursor/skills-cursor/arloui`              |
| Claude Code     | Supported   | `~/.claude/skills/arloui`                     |
| Codex CLI       | Supported   | `./arloui` referenced from `AGENTS.md`        |
| Other agents    | Best-effort | Any tool that reads `SKILL.md` / `AGENTS.md`  |
